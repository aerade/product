# Keyflow — запуск прототипа

## Что понадобится

- Windows 10/11, Node.js 22+ и Python 3.12+.
- Интернет нужен только для установки зависимостей при первом запуске.

## Первый запуск

Распакуйте проект, откройте PowerShell в его папке и выполните:

```powershell
npm ci
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
npm run build
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. Если `py` не найден, замените `py -m venv .venv` на `python -m venv .venv`.

Регистрация, вход и общий рейтинг доступны при запущенном backend. Гостевой режим работает в браузере без регистрации.
