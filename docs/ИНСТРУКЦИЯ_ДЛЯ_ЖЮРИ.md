# Keyflow — запуск прототипа

## Что понадобится

- Windows 10/11, Node.js 22+ и Python 3.12+.
- Интернет нужен только для установки зависимостей при первом запуске.

## Первый запуск

Распакуйте проект, откройте PowerShell в его папке и выполните:

```powershell
npm ci
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
npm run build
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. Если `py` не найден, замените `py -m venv .venv` на `python -m venv .venv`.

## Что показать

1. На странице тренировки переключите язык и режим, выберите сложность и отображение по символам или словам.
2. Начните упражнение, следуйте подсказкам клавиатуры и пальца; ошибитесь или пропустите символ, чтобы показать подсчёт ошибки и сброс серии.
3. Продолжите печатать, чтобы продемонстрировать бонусы, множитель серии, статистику и экран результата.
4. Откройте прогресс: историю, графики скорости/точности по дням/неделям и частые ошибки.
5. Откройте рейтинг и переключите показатель и период. До появления реальных результатов показываются демонстрационные участники с отметкой «Бот».
6. При необходимости зарегистрируйте аккаунт и войдите: результаты аккаунта сохраняются в локальной базе SQLite.

Регистрация, вход и общий рейтинг доступны при запущенном backend. Гостевой режим работает в браузере без регистрации.
