# Keyflow

Браузерный тренажёр печати для отборочного этапа «Киберрывок 2026». Работает на компьютере и телефоне.

## Возможности

- Четыре режима: слова, предложения, код и символы; русский и английский языки, восемь уровней сложности.
- Подсветка текущего символа, подсказка клавиши и пальца, живые WPM/CPM, точность, ошибки и время.
- Серии без ошибок, множители очков, случайные бонусы, XP, уровни и 14 достижений пяти редкостей с отдельными пиксельными иконками и карточками. У каждой карточки есть состояния «Открыто» и «Закрыто»; условия достижений указаны на карточках.
- История занятий, график скорости, анализ сложных символов и рейтинг по скорости, точности или XP.
- Гостевой режим хранит результаты в этом браузере. Аккаунт хранит их в SQLite и открывает на другом устройстве после входа.
- Десять аватаров. Новый аккаунт получает случайный аватар; сменить его можно в окне настроек.
- Окно настроек: чёрно-белая тема по умолчанию, цветные темы и собственная палитра, предпросмотр тем, шрифт, плотность, навигация, визуальные эффекты, звуковые наборы, подсказки и параметры тренировки.

## Локальный запуск

Нужны Node.js 22+ и Python 3.12+.

```powershell
npm ci
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

В другом терминале:

```powershell
npm run dev
```

Откройте адрес Vite, напечатанный в терминале (обычно `http://localhost:5173`). Vite перенаправляет запросы `/api` на `http://127.0.0.1:8000`. Без API доступны гостевые тренировки, а аккаунты и общий рейтинг не работают.

Для Linux/macOS команды создания окружения: `python3 -m venv .venv`, установка через `.venv/bin/python -m pip install -r backend/requirements.txt` и запуск через `.venv/bin/python -m uvicorn backend.main:app --reload`.

## Один процесс для просмотра или размещения

```powershell
npm run build
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. FastAPI раздаёт собранный интерфейс и API с одного адреса. База создаётся автоматически в `data/typing.db`; путь можно изменить через `APP_DB_PATH`.

С Docker: `docker compose up --build -d`. Контейнер слушает локальный порт 8000; для доступа из интернета разместите перед ним HTTPS reverse proxy и задайте `COOKIE_SECURE=1`. Том `product_data` сохраняет аккаунты и результаты между перезапусками. На сервере регулярно сохраняйте резервную копию тома.

## API

После запуска документация доступна по `/docs`.

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| POST | `/api/auth/logout` | Выход |
| GET | `/api/auth/me` | Текущий пользователь |
| PATCH | `/api/profile` | Имя и аватар |
| POST | `/api/practice` | Сохранить тренировку |
| GET | `/api/progress` | Статистика аккаунта |
| GET | `/api/leaderboard` | Рейтинг; параметры `metric` и `period` |
| GET | `/api/healthz` | Проверка доступности |

Сессия аккаунта хранится в HttpOnly cookie. Пароли хешируются с `scrypt`, а в базе сохраняется только хеш токена сессии. Рейтинг скорости и точности учитывает занятия длиной от 25 символов и 15 секунд. Результаты отправляются клиентом и проходят базовую проверку пределов; для публичного соревновательного запуска понадобится серверная проверка упражнений и защита от накрутки.

## Структура

`src/` — React, TypeScript и стили; `public/` — логотип Keyflow, 10 аватаров, иконки достижений, карточки пяти редкостей и локальный пиксельный шрифт Press Start 2P (лицензия OFL в `public/fonts/`); `backend/` — FastAPI и SQLite; `data/` — локальная база (игнорируется Git); `dist/` — собранный интерфейс (игнорируется Git).
