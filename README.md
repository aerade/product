# Keyflow

Браузерный тренажёр слепой печати для отборочного этапа «Киберрывок 2026». Интерфейс адаптирован для компьютеров и телефонов.

## Возможности

- Четыре режима — слова, предложения, код и символы; русский и английский языки; восемь уровней сложности.
- Отображение упражнения по символам или целым словам, подсветка текущего фрагмента и ошибок, виртуальная клавиатура с подсказкой клавиши и пальца. Символ можно пропустить кнопкой или клавишей `→`; пропуск считается ошибкой.
- Во время занятия отображаются скорость (WPM и символы в минуту), точность, ошибки и время. Серии без ошибок увеличивают множитель очков; случайные бонусы временно дают больше очков или опыта.
- Опыт повышает уровень и открывает режимы и сложности. Есть достижения, история занятий, анализ сложных символов и графики скорости или точности по дням и неделям.
- Рейтинг показывает скорость, точность или опыт за день, неделю и всё время. Для пустого рейтинга предусмотрены демонстрационные участники с пометкой «Бот».
- Гостевой режим сохраняет прогресс в текущем браузере. Учётная запись хранит результаты в SQLite и синхронизирует их при входе с другого устройства.

## Требования

- Node.js 22 или новее.
- Python 3.12 или новее. Команды ниже используют установленную по умолчанию версию Python и не привязаны к номеру minor-релиза.

Проверьте версии:

```powershell
node --version
py --version
```

## Локальный запуск

Из корневой папки проекта выполните в PowerShell:

```powershell
npm ci
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

В другом окне PowerShell:

```powershell
npm run dev
```

Откройте адрес Vite из терминала (обычно `http://localhost:5173`). Если команда `py` не установлена, используйте `python -m venv .venv` и дальше те же команды виртуального окружения.

Без backend доступны гостевые тренировки; регистрация, вход и общий рейтинг требуют запущенного API.

## Запуск собранного приложения

```powershell
npm ci
npm run build
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Затем откройте `http://127.0.0.1:8000`. FastAPI раздаёт собранный интерфейс и API с одного адреса. SQLite-база создаётся автоматически в `data/typing.db`; путь можно изменить через `APP_DB_PATH`.

Для Linux/macOS создайте окружение командой `python3 -m venv .venv`, установите зависимости через `.venv/bin/python -m pip install -r backend/requirements.txt` и запускайте backend через `.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000`.

## Docker

```sh
docker compose up --build
```

Приложение будет доступно на порту 8000. Для размещения в интернете используйте HTTPS reverse proxy и задайте `COOKIE_SECURE=1`. Том `product_data` хранит базу между перезапусками. Перед публичным соревновательным запуском потребуется серверная проверка упражнений и дополнительная защита от накрутки результатов.

## API

После запуска документация доступна по `/docs`.

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| POST | `/api/auth/logout` | Выход |
| GET | `/api/auth/me` | Текущий пользователь |
| PATCH | `/api/profile` | Имя и аватар |
| POST | `/api/practice` | Сохранение тренировки |
| GET | `/api/progress` | Статистика и история |
| GET | `/api/leaderboard` | Рейтинг; параметры `metric` и `period` |
| GET | `/api/healthz` | Проверка доступности |

Сессия аккаунта хранится в HttpOnly cookie, пароли хешируются `scrypt`. Рейтинг учитывает тренировки длиной от 25 правильных символов и длительностью от 15 секунд.

## Структура проекта

- `src/` — интерфейс на React, TypeScript и CSS.
- `public/` — изображения интерфейса, аватары, достижения и локальный шрифт Press Start 2P (лицензия OFL находится в `public/fonts/`).
- `backend/` — API на FastAPI и работа с SQLite.
- `docs/ИНСТРУКЦИЯ_ДЛЯ_ЖЮРИ.md` — краткий сценарий запуска и показа прототипа.
- `data/`, `dist/` — локальная база и собранный интерфейс; не хранятся в Git.
